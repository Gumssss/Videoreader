# Image Reader

## Usage
### Setup environment
```bash
pip install Flask transformers pillow soundfile kokoro
git clone https://github.com/JasonZuu/Image2Audio
cd Image2Audio
```

### Run the code 
```
python app.py
```

and then use it as you want on your browser.

### Turn your images to audio
There are currently only one function that turns the images into the audio, and two ways to upload images
1. upload through indicating the local file path.
2. upload through capturing the photo using your computer's camera.
